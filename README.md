# Proyecto Final DAW - Relocation Services

Aplicación web desarrollada como proyecto final del ciclo de Desarrollo de Aplicaciones Web.

## Descripción

El proyecto consiste en una aplicación web para una profesional autónoma dedicada a ofrecer servicios de relocation a clientes que necesitan ayuda en procesos de traslado, adaptación y gestión inicial en una nueva ciudad o país.

## Tecnologías previstas

- HTML5
- CSS3
- JavaScript
- PHP
- MySQL
- Git y GitHub

## Funcionalidades previstas

- Página de inicio informativa.
- Página de servicios.
- Página sobre la empresa.
- Formulario de contacto.
- Panel de administración.
- Gestión de solicitudes de clientes.
- CRUD de servicios.
- Login de administrador.
